Rumee — Meesho Tab

Where did the payout actually go

LIVE
2026-07-24

Meesho's payout math is unusually opaque -- gross sale minus returns minus shipping minus TCS/TDS, several deductions deep before you see the number that actually lands in the bank. This tab exists mainly to demystify that gap, plus the same GMV/orders/RTO trend the other platform tabs show.

the shared pipeline / the tab itself ――― dashed = written to Firestore, not yet displayed anywhere
01

Meesho tab has no loader of its own

Unlike Flipkart, the Meesho tab doesn't fetch any Firestore collection when you open it -- it simply re-renders the same trend/KPI/funnel/SKU functions Master already loaded, filtered to Meesho's own numbers. Opening the tab is instant because the data is already sitting in memory.

02

Settlement Breakdown -- the actual demystifier

Gross Sale → Returns Deducted (with % of gross shown) → Return Shipping → Forward Shipping → Net Settlement (highlighted) → TCS + TDS deducted (labelled "Recoverable via ITR filing" so it doesn't read as a pure loss). This card is fed by an uploaded Payments Excel file, not a live Firestore collection -- if it says "Upload Payments XLSX to see breakdown," that upload simply hasn't happened yet for the period you're viewing.

03

Claims -- Meesho's own shape

Meesho claim tickets track differently from Flipkart's: total tickets, how many are open, ₹ recovered so far, and a "Deadline ≤5 days" count -- tickets about to lose their reopen eligibility window, so nothing quietly expires unnoticed.

Worth knowing

Meesho's ad spend on this tab is only ever the single monthly total baked into the summary blob -- there's no daily/campaign/keyword breakdown here the way Flipkart gets one.

Not yet built

The pipeline already writes rumee_me_ads_daily/rumee_me_ads_catalog to Firestore (checked for pipeline health on the Data Pipeline tab), but no dashboard tab reads either collection yet -- the data exists, it's just not wired into a UI. A genuine future item, not a bug.
