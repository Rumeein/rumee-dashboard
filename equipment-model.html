Rumee — Equipment Tab

A filter, not a data store

LIVE
2026-07-24

Equipment has no Firestore collection of its own. Every row you see here is a real Purchases line item -- the entire tab is one boolean flag, checked line by line, against data that already lives on the Purchases tab.

the Equipment tab's own filter step
01

One flag, set at the category level

A line item counts as equipment purely through its CATEGORY's "Track as Equipment (non-stock)" checkbox, set once in Purchases → Manage Categories -- never chosen per individual line. Tag a whole category once, and every purchase under it (past and future) shows up here automatically.

02

Same data the Purchases tab already loaded

Opening this tab loads the exact same purchase report and category list the Purchases tab uses -- no separate fetch, no separate source of truth. It then walks every purchase's line items and keeps only the ones whose category is flagged.

03

Read-only, on purpose

The only action here is "Details," which jumps back to the real purchase record on the Purchases tab and expands it there. There is no edit path on this tab at all -- equipment purchases are edited exactly the same way any other purchase is, just from the other tab.

Worth knowing

If a tool purchase isn't showing up here, the fix is never on this tab -- check whether its Purchases category actually has "Track as Equipment" ticked in Manage Categories.
